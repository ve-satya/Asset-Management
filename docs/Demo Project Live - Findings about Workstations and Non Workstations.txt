## What is Asset in ServiceDesk Plus?

In ServiceDesk Plus, an **asset** means any item owned/used by the organization and tracked for inventory, ownership, maintenance, warranty, purchase, location, and lifecycle.

Examples:

**IT Assets**
Laptop, desktop, workstation, server, router, switch, printer, mobile, access point.

**Non-IT Assets**
Table, chair, projector, scanner, desk phone, furniture, UPS, office equipment.

ServiceDesk Plus allows tracking IT, non-IT, software, components, consumables, financial data, contracts, ownership, barcode/QR scan, and import from Excel/CSV. ([ServiceDesk Plus Help Guide][1])

## What is Workstation?

A **Workstation** is normally a computer device used by an employee/user.

Examples:

| Asset                       | Workstation? |
| --------------------------- | ------------ |
| Office desktop PC           | Yes          |
| Laptop assigned to employee | Yes          |
| Developer machine           | Yes          |
| Reception computer          | Yes          |
| Lab computer                | Yes          |

A workstation usually has:

| Detail             | Example                               |
| ------------------ | ------------------------------------- |
| Asset name         | DESKTOP-HR-001                        |
| User               | Amit Sharma                           |
| Department         | HR                                    |
| Location           | Head Office                           |
| IP address         | 192.168.1.25                          |
| Serial number      | ABC12345                              |
| OS                 | Windows 11                            |
| RAM                | 16 GB                                 |
| Processor          | Intel i5                              |
| Installed software | MS Office, Chrome                     |
| Warranty           | 3 years                               |
| Status             | In Use / In Store / Repair / Disposed |

In ServiceDesk Plus Cloud, default product types include **Computer, Workstation, Server, Router, Printer, Switch, Virtual Machine, Mobile, Smartphone, Tablet**, etc. ([SDP Ondemand Help][2])

## What is Non-Workstation?

**Non-Workstation** means assets that are **not employee computers/laptops**.

It can include both IT and Non-IT assets.

Examples:

| Asset     | Non-Workstation? | Type                         |
| --------- | ---------------: | ---------------------------- |
| Printer   |              Yes | IT Asset                     |
| Router    |              Yes | IT Asset                     |
| Switch    |              Yes | IT Asset                     |
| Server    |              Yes | IT Asset                     |
| Projector |              Yes | Non-IT / Facility Asset      |
| Scanner   |              Yes | IT or Non-IT depending setup |
| Chair     |              Yes | Non-IT Asset                 |
| Table     |              Yes | Non-IT Asset                 |
| UPS       |              Yes | IT/Non-IT Asset              |
| Keyboard  |              Yes | Component                    |
| Mouse     |              Yes | Component                    |

ServiceDesk Plus defines IT assets as IP-based devices involved in IT service delivery, such as workstations, servers, routers, switches, mobile devices, and printers. Non-IT assets are non-IP based items indirectly tied to IT services, such as projectors, scanners, and similar equipment. ([ServiceDesk Plus Help Guide][1])

## Simple Difference

| Point                        | Workstation            | Non-Workstation                          |
| ---------------------------- | ---------------------- | ---------------------------------------- |
| Meaning                      | User computer/laptop   | Any asset other than user computer       |
| Used by                      | Employee/user directly | User, department, site, network, office  |

## How Workstation Works in Asset Management

Typical flow:

### 1. Asset is added

Workstation can be added by:

Manual entry, network scan, barcode/QR scan, or Excel/CSV import.

### 2. System captures details

For workstation, system can store:

Computer name, IP address, MAC address, OS, processor, RAM, hard disk, installed software, service pack, serial number, asset tag.

### 3. Asset is assigned

Example:

Laptop `LT-HR-004` assigned to employee `Ravi Kumar`.

Once assigned, asset status becomes **In Use**.

### 4. Asset is linked with service requests

Example:

Employee raises ticket: “Laptop keyboard not working.”

The ticket can be linked to that workstation asset. IT team can see asset history, warranty, user, location, and previous issues.

### 5. Lifecycle is tracked

Asset states may be:

In Store → In Use → Under Repair → Expired → Disposed.

### 6. Reports are generated

Admin can generate reports like:

Total workstations, assigned laptops, warranty expiring, old machines, department-wise assets, user-wise assets.

## Product Type, Category, and Asset Type

ServiceDesk Plus uses classification like this:

| Level        | Meaning                      | Example                      |
| ------------ | ---------------------------- | ---------------------------- |
| Category     | IT or Non-IT                 | IT                           |
| Type         | Asset, Component, Consumable | Asset                        |
| Product Type | Group of similar assets      | Workstation, Printer, Router |
| Product      | Actual model/product         | Dell OptiPlex 3090           |
| Asset        | Actual physical item         | DESKTOP-001                  |

ManageEngine documentation says **Product Type** is used to group similar assets, and **Workstation** is one such product type. ([ServiceDesk Plus Help Guide][3])

## My Feedback

For your own ERP, do not make asset management too complex in the first version. Keep these main groups:

1. **Workstation / Computer Assets**
   Desktop, laptop, computer lab machines.

2. **IT Non-Workstation Assets**
   Printer, router, switch, CCTV, biometric machine, projector, smart board.

3. **Non-IT Assets**
   Table, chair, bench, fan, AC, furniture, vehicle, library rack.

4. **Components**
   Keyboard, mouse, RAM, hard disk, adapter.

5. **Consumables**
   Printer ink, paper, chalk, stationery, lab materials.

This structure will be easy to manage, easy to import from Excel, and suitable for future reporting.
